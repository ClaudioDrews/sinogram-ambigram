# De-biasing report: before and after

> Generated by `code/stage11_debias_report.py` from `data/rotation_pairs.csv`
> (v1) and `data/v2/` (v2). Every number below is reproducible.

The v1 ranking compares raw distances between glyphs. The v2 ranking
compares each pair against the null distribution of its own characters,
and searches for the rotation centre that fits the pair best. This
report measures what that changed, and applies the decision rule frozen
in `findings/anchors.txt`.

## 1. What changed

| | v1 | v2 |
|---|---|---|
| Ranking quantity | raw exact Hausdorff | per-glyph z-score, within complexity stratum |
| Rotation centre | fixed at the box centre | searched on a 9 × 9 grid |
| Null model | none | 30 random partners per glyph, seed 20261107 |
| Stratum | none | rounded mean stroke count |

## 2. Density bias

Spearman correlation between the ranking quantity and stroke count, on
the 2770 self-rotation pairs:

| Quantity correlated with stroke count | ρ |
|---|---|
| v1 raw Hausdorff | **-0.419** |
| v2 raw Hausdorff (same pairs, for reference) | -0.419 |
| v2 z-score | **-0.026** |

The z-score reduces the correlation with stroke count from -0.419 to -0.026. The residual correlation is the part of the density effect that the per-glyph null does not remove.

## 8. What this does not establish

Nothing in this report is evidence that any pair is readable. The
de-biasing changes which pairs the geometry prefers; whether a
construction is legible to a reader is the question the pilot and the
full study address, and no such study has been run. The anchor rule
decides whether the metric change preserved what the geometry already
found, nothing more.

The enclosure bias described in `findings/known-biases.md` §4 is **not**
addressed by the z-score: a skeleton metric cannot see whether two
frames contain the same interior. An ink-area metric would.
